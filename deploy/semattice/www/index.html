QUICKSTART

同一个能力，三种调用方式

示例使用只读能力 system.capability.list。正式令牌由统一身份服务签发，必须包含租户、组织、主体、有效期与所需 scope。

01 / HTTPS

REMOTE TRANSPORT

功能 API

公网可用

所有原子能力使用统一入口：POST /v1/capabilities/{capability-id}/invoke。身份由 Bearer JWT 绑定，调用方不能用请求体伪造 tenant 或 actor。

shell
export SEMATTICE_TOKEN='<short-lived-jwt>'

curl -sS \
  'https://semattice.agentcici.com/v1/capabilities/system.capability.list/invoke' \
  -H "Authorization: Bearer ${SEMATTICE_TOKEN}" \
  -H 'Content-Type: application/json' \
  --data '{
    "request_id": "req-capability-list-001",
    "input": {}
  }'
Success200 · status=succeeded
No token401 · UNAUTHENTICATED
No scope403 · UNAUTHORIZED

BINARY CLI / TRUSTED HOST

二进制 CLI 没有菜单或确认提示，只读取 flags/stdin JSON，并向 stdout 输出单个 JSON。当前 CLI 在进程内加载 Capability Runtime，完整业务能力需要受控数据库与身份环境。

shell
chmod 700 ./semattice-linux-amd64
export AI_NATIVE_IDENTITY_ISSUER='https://semattice.agentcici.com'
export AI_NATIVE_IDENTITY_AUDIENCE='semattice-api'
export AI_NATIVE_IDENTITY_ALGORITHM='HS256'
export AI_NATIVE_IDENTITY_HMAC_KEY='<secret-from-secure-store>'
export AI_NATIVE_IDENTITY_TOKEN='<short-lived-jwt>'
export AI_NATIVE_CONTROL_DATABASE_URL='<controlled-postgres-url>'
export AI_NATIVE_RUNTIME_DATABASE_URL='<rls-runtime-postgres-url>'

printf '%s' '{
  "request_id":"req-cli-001",
  "input":{}
}' | ./semattice-linux-amd64 capability invoke \
  --id system.capability.list
semattice capability list semattice capability describe --id <id> semattice capability invoke --id <id>
03 / STDIO

MODEL CONTEXT PROTOCOL

MCP Tool Server

stdio

MCP 客户端启动 Semattice 子进程并通过 stdio 交换 JSON-RPC。能力 ID 会映射为工具名，例如 system.capability.list → system_capability_list。当前版本不暴露远程 HTTP MCP。

mcp.json
{
  "mcpServers": {
    "semattice": {
      "command": "/usr/local/bin/semattice",
      "args": ["mcp", "stdio"],
      "env": {
        "AI_NATIVE_IDENTITY_ISSUER": "https://semattice.agentcici.com",
        "AI_NATIVE_IDENTITY_AUDIENCE": "semattice-api",
        "AI_NATIVE_IDENTITY_ALGORITHM": "HS256",
        "AI_NATIVE_IDENTITY_HMAC_KEY": "<secret-from-secure-store>",
        "AI_NATIVE_IDENTITY_TOKEN": "<short-lived-jwt>",
        "AI_NATIVE_CONTROL_DATABASE_URL": "<controlled-postgres-url>",
        "AI_NATIVE_RUNTIME_DATABASE_URL": "<rls-runtime-postgres-url>"
      }
    }
  }
}

调用工具时，认证模式只需提交 request_id、可选 idempotency_key 与领域 input；tenant、actor、scopes 和 approvals 均从已验证令牌绑定。
