# PROJECT-BASELINE

## 项目概览

- 当前项目做什么
- 当前最活跃的交付方向是什么
- 为什么现在要把它纳入这套协议

## Verified Facts

- 已确认的架构事实
- 已确认的模块边界
- 已确认的运行、构建、部署入口

## Inferred Facts

- 基于代码或现象推断出的结构
- 尚未完全验证但当前工作依赖的理解

## Pending Verification

- 还不能确定的系统行为
- 需要后续验证的命令、依赖、配置或边界

## Legacy Hotspots

- 风险高、耦合重、缺文档的模块
- 当前不建议贸然改动的区域

## Key Entry Points

- 代码入口
- 配置入口
- 测试入口
- 运维入口

## Active Delivery Surface

- 当前正在推进的功能或任务范围
- 与 `task-board.md` 对应的任务 ID

## Adoption Plan

- 先接入哪些状态文件
- 哪些模块等真正变更时再补 feature spec
- 哪些历史内容不需要立刻补齐

## Handoff Notes

- 新接手的智能体先看哪些文件
- 先跑哪些命令
- 哪些地方最容易踩坑
