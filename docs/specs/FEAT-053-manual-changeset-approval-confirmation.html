Semattice Feature Spec · FEAT-053

Changeset 开发期手工确认

当前状态：已完成生产发布和真实 Changeset 验证；商城元数据 sequence 3 已激活。

目标

在审批申请服务尚未实现的开发阶段，允许 metadata.changeset.approve 使用明确、非空的手工 approval_id，并保持 Scope、租户隔离、状态机、幂等和审计要求。

接口行为

{
  "changeset_id": "<uuid>",
  "approval_id": "<non-empty-manual-confirmation-id>"
}
  • 空白确认 ID 返回 FAILED_PRECONDITION。
  • 非空 ID 不要求存在于 OACT 的 approvals 声明。
  • 审批审计写入 approval_id 和 approval_mode=manual。

不变边界

purge、rollback、授权、共享和组织合并仍要求可信审批；本次不实现审批中心，也不新增数据库迁移或历史兼容逻辑。

验收

  • 无 approvals claim 的主体可审批 validated Changeset。
  • 空白确认仍失败，审计模式可回读。
  • 生产构建、原子发布、能力发现、真实审批和发布回读通过。

生产 release：20260805T020849Z-web-oidc-5f5bdcea97d2。商城 Changeset 已发布为活动版本，回读结果为 28 个对象、391 个字段和 70 个关系。

风险：手工确认弱于独立第二人审批，仅适用于当前开发阶段；调用前必须展示并核对完整候选模型或模拟结果。
