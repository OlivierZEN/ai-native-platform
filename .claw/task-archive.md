# 任务归档

`task-archive.md` 保存从 `task-board.md` 中移出的已完成或已取消任务卡。

## Archived Tasks

- 暂无归档任务。

## 维护规则

- 这里只归档 `done` 或 `canceled` 的任务。
- 当 `task-board.md` 中的 `Completed Tasks` 超过 20 条时，将最旧的任务卡移动到这里。
- 保留任务 ID、最终状态、相关 issue、主要变更范围和必要交接信息。
- 归档是移动，不是删除；不要让任务历史凭空消失。
